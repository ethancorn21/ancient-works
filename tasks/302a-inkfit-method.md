# 302a: The ink-fit method - plate ink against LiDAR relief, no model coordinates
Touches: fit/inkfit.py, requirements.in, requirements.txt, data/inkfit/

## Goal
The new module `fit/inkfit.py`: an automatic fit of one candidate picture of one site whose matching
points come from the pictures themselves - the plate's ink (extracted with `pipeline/autowalls.py`'s
frozen config, docs/autofit.md section 3) matched against the site's bare-earth relief with
`fit_plate`'s ridge-contrast objective, searched with `pipeline/autofit.py`'s coarse-FFT + refine
machinery from a seed that never touches the hand fit (scale/north/centre from `fit/propose.py`'s
anchor or a coarse default; the vision model may give a starting guess and classify ink pieces, never
a coordinate). Output: a placement (Mercator similarity) plus N ink-point pairs (plate px in the doc's
size frame -> lon/lat, irregularly chosen so plan_fit.fabrication_pattern cannot fire) and a
confidence score built on a search-matched null (docs/autofit.md section 4 finding 2: the same search
on a scrambled template and/or a shifted DEM box, whichever scores higher), ready to decide sync vs
review queue. The model step is injectable with a deterministic no-model fallback (this VM cannot
reach the AI box; see the parent hand-over).

**Design (the whole of it; all parameters below are FROZEN - do not change after seeing smoke results without labelling it exploratory):**
- `fit(site, picture, model=None, root=None, n_refine=8, null=True) -> dict`. `site`: a web/data/sites.json entry dict or its id string. `picture`: a web/data/plans.json row dict (must have "id"). `root=None` = this checkout (tests pass their temp tree). Returns `{"site","plan","doc", "placement", "confidence", "objective", "null", "seed", "gate", "fabrication", "n_points","n_pieces","reason","model","seconds"}`. `doc` = the full platefit document (batch_us.write_doc shape + `"fitter": "ink"`, `"auto": true`; crop = map_box*size or full frame, pairs in the size frame 1 dp / 7 dp). `reason` non-None => review queue. 302c applies the sync threshold on `confidence` (this task does not bake one in).
- **Relief** (frozen): box = `aw.site_bbox(site.lon, site.lat, size_m or (1000,1000))`, `px_m = 1.0` (NEVER read data/sites/<id>/site.json - it carries hand-fit knobs). Loader order: `<root>/data/inkfit/relief/<sid>.npz` (keys z float64 h×w metres NaN=nodata, px_m float, bbox 4 Mercator floats; shape must match w,h else clear error) -> `<root>/data/sites/<sid>/dem.npy` (single array, same w×h expected else refetch) -> `aw.fetch_dem` (network, working phase only; saves the dem.npy cache). LRM = `aw.local_relief(z, px_m, radius_m=24.0)` clipped to ±1.0 m, then masked NaN by `aw.modern_mask` + `aw.water_mask` (fit_plate's recipe, default knobs).
- **Template** (frozen = docs/autofit.md section 3 as-is): `autowalls.extract(panel_image, boxes, debug=True)` with `autowalls.P` unmodified; pieces = `autowalls`-labelled connected components of the returned `keep` mask (3-conn `ndi.label`, or reuse `autofit_pieces.pieces(sampled_pts, r=8.0, min_pts=15)` - the latter is a pure function, safe to import: llm.py has no import-time network, verified). **No-model fallback (frozen rule): boxes = [] (no blanking beyond the 20 px margin; the length filter drops lettering), pieces = keep ALL.** Model duck-typing: `model.boxes(im) -> [(kind,(x0,y0,x1,y1))]` 0-1000-normalised over the panel image (blank kinds per autowalls P["box_kinds"]); `model.label_pieces(im, pieces) -> {piece_index: kind}` (keep kind=="wall" only; missing/None/unusable answer -> keep all, labelled as no-model variant in the result).
- **Picture loading**: book row -> `<root>/data/raw/books/<ia>/full/<file>`, crop = `map_box` in the row's size frame (full frame if no map_box); commons row -> `<root>/data/raw/commons/big/<id>.jpg` else `<root>/data/raw/commons/<site>/<id>.jpg` (the row's `url` tail) else `plan_fit.load_picture(pseudo-doc {src:"commons", plan:id, ref, size, ia, file})` (network). `fs = im.width/size[0]`; panel px -> size frame: `u = pu/fs + x0, v = pv/fs + y0`. Missing image in a hermetic tree = clear error (302c's test seeds the image into the temp tree).
- **Seed** (frozen): `fit/propose.propose_for(site_id, plan_id)` -> s0 = scale_m_px, rot0 = rot_deg (north-up fallback is inside propose); on ValueError/KeyError: s0 = max(site.size_m)/max(panel px extent) (propose._picture_scale formula), rot0 = 0. t0 = (0,0) (the anchor maps the panel centre to the site centre = the relief box centre).
- **Search** (frozen = autofit.py's 10-10 constants, reused read-only): single seed via `autofit.fit_site(S, P, N, w, [one seed], n_refine=n_refine)` where my `InkSite` exposes `hand_s=s0, hand_rot=rot0, hand_t=t0` and seed dict `{scale_factor:1.0, rot_offset_deg:0.0, centre_offset_m:[0,0]}`; window WIN_ROT ±25°, WIN_LOGS ×0.74..×1.36, WIN_T ±200 m, ROT_STEP 2°, LOGS_STEP 0.04, CELL_M 4.0, K_BINS 8, NEG_FLOOR -0.2; objective = mean max(contrast, -0.2), contrast = fit_plate's ridge contrast (line minus higher side at side_m=20, ≥50% valid else -9). InkSite must implement every attribute autofit's functions touch: lrm, px_m, side_m, W_m, H_m, w, h, c0=(panel-centre in size frame), to_ground, relief_at, contrast, score, corners_ground (+ hand_s/rot/t; corner_rms not needed here).
- **Null (search-matched, frozen recipe)**: `null = max` of the SAME search (identical seed/window/grid/n_refine) over (a) the **scrambled template**: each piece rigidly rotated U(0,2π) and its centre translated by U(-0.4..0.4)×(panel W, H) px, clamped to stay inside the panel, all from `np.random.default_rng(20261012)`; reuses the SAME Coarse (ground unchanged); and (b) the **shifted DEM**: `scipy.ndimage.shift(lrm, (H_m/2/px_m, W_m/2/px_m), order=0, cval=nan)` (half box north + half box east; a new Coarse). `confidence = obj_fit - null`. If fewer than 100 valid draws in a null search, record it (newark's 10-10 problem) and let max() handle it (obj -9 counts low).
- **Pairs** (frozen, anti-fabrication by construction): sort kept pieces by length desc; take up to 2 sampled points per piece at FRACTIONAL positions 0.23 and 0.71 (never a fixed stride - clause (b) fires on ≥3 evenly spaced collinear points), longest pieces first, max 10 points, need ≥ 4 else reason "not enough wall ink"; map each to lon/lat through the best placement; round 1 dp / 7 dp; then `plan_fit.fabrication_pattern(pairs)` must be None - if a clause fires, re-draw with `default_rng(20261012 + attempt)` (same rules) up to 8 attempts, else reason = the pattern string. Also gate = `fit_gate.gate(pairs, (a,b))` (accepts by construction - residuals are 0, gate section 7's documented limit; record stats, it is a defence layer only).
- **Placement -> doc** (VERIFIED derivation, re-check with the script below): ground frame: `en = M@[u-u0c, -(v-v0c)] + t`, M = [[s·c, -s·sn],[s·sn, s·c]], t = best (tE,tN) metres from relief-box centre; lon/lat = `aw.to_lonlat(cx + e/k0, cy + n/k0)` with k0 = ground_scale(lat) - i.e. Mercator offset = ground offset × (1/cos(lat)) exactly as fit_plate does (`cx,k = ...; corners.append(to_lonlat(cx + e*k, cy + n*k))`, k = 1/ground_scale). Mercator similarity in plan_fit convention (w = u - i v): `a = (s / k0) * e^{i rot}` (= k·s·e^{iθ}, matches propose._anchor_pairs), `b = (cx + i·cy) + k·(tE + i·tN) - a·complex(u0c, v0c)`.
