### 3.1 `fit/review.py` — item format, export, resolution (boxes 1, 3, 4)

Item file **`data/review/<site>.<lead-plan>.json` — one item per site** (goal: "every built site without a
fitted drawing gets a review item"); `<lead-plan>` = best candidate's plan id (matches the platefit doc naming
`<site>.<plan>`). Recommended shape (the contract for 203a/b and 212):

```json
{
  "site": "bibracte-q650053",
  "candidates": [
    { "plan": "somebook_n0001_1",
      "title": "…",                       // row's title (or the picture's name for commons)
      "evidence": { "…": "200's field, verbatim, only when present" },
      "url": "books/<ia>/<file>",         // or "media/commons/<site>/<h>.jpg" — exactly what openPlan loads
      "pairs": [[u, v, lon, lat], ...],   // platefit format, page px of the candidate's image (row size) -> ground
      "coarse": true }                    // 202's coarse flag, when set
  ],
  "no_picture_found": null,               // or {"searched": [...], "at": …} (212's box)
  "resolved": null                        // or {"doc": "<site>.<plan>", "at": "<iso>"} — written by the export
}
```

Export (stdlib-only module with `main()`; CLI like `python3 fit/review.py [--root <project>]`; idempotent;
212 imports/runs it):
1. read every item in `data/review/`; **merge files that share a site** (insurance if 203a/b write one file per
   rejected (site, plan) instead of one per site — merging by site makes both granularities work);
2. **resolve**: item is OPEN iff `resolved` is null AND no `data/db/platefits/<site>.<lead>.json` exists.
   When a file's lead doc exists, write `resolved: {doc, at: <doc's at>}` back into the item file (this is the
   "with the saved doc id recorded" of box 3 — the doc id is exactly `<site>.<plan>`). See Risks R1.
3. write `web/data/review.json`: `{"at": <export time>, "items": [{site, site_name, lead, candidates:
   [{plan, title, evidence?, url, pairs, coarse?}], no_picture_found?}]}` — **open items only**, sorted by
   site name; `site_name` joined from web/data/sites.json (name always present). The page's count =
   `items.length` — computed, not hardcoded (box 4).
Seed in main: one real item (pick a site with no drawing, e.g. an aerial-only one like bibracte-q650053 so the
aerial branch is real) + `web/data/review.json` as its current export, so the page works out of the box.
